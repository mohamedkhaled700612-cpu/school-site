BATANOON AI 2.0 — خطوات التشغيل

مهم: GitHub Pages يستضيف ملفات ثابتة فقط. لذلك يوجد ملف ai-worker.js ليعمل كوسيط آمن بين الموقع وPollinations. لا تضع مفتاح Pollinations داخل index.html أو أي ملف منشور للعامة.

1) أنشئ Cloudflare Worker جديدًا باسم batanoon-ai. لا تستبدل Worker الإشعارات الحالي.
2) انسخ محتوى ai-worker.js إلى محرر Worker الجديد ثم Deploy.
3) من Worker > Settings > Variables and Secrets أضف Secret باسم POLLINATIONS_API_KEY وضع فيه مفتاح Pollinations الخاص بك. لا ترسله في المحادثة ولا تضفه إلى GitHub.
4) في index.html ابحث عن السطر:
   const BATANOON_AI_WORKER = "https://YOUR-BATANOON-AI-WORKER.workers.dev";
   واستبدل الرابط برابط Worker الجديد، مع الإبقاء على /chat التي يضيفها الكود تلقائيًا.
5) اسمح في إعدادات Worker بالمصدر https://mohamedkhaled700612-cpu.github.io فقط إذا كان هذا هو نطاق الموقع المنشور. لو نطاقك مختلف، عدّل ALLOWED_ORIGIN داخل ai-worker.js قبل النشر.
6) أضف Rate Limiting rule على مسار /chat لتقليل إساءة الاستخدام، وراقب استهلاك حساب Pollinations. لا تفعّل وصولًا عامًا غير محدود.
7) ارفع index.html فقط إلى GitHub Pages بعد وضع رابط Worker. ملف ai-worker.js لا يحتاج رفعه إلى GitHub Pages؛ انسخ محتواه إلى Cloudflare Worker.

القدرات المضافة في الواجهة:
- محادثة متتابعة وسجل محلي منفصل لكل حساب على نفس الجهاز.
- اختيار الصف الدراسي يدويًا.
- أوضاع الشرح والاختبار والتصحيح.
- إرفاق صورة سؤال حتى 5MB وإرسالها لنموذج يدعم الرؤية.
- استرجاع أحدث بيانات الأخبار والجداول والملفات وبنك الأسئلة من Firestore عند السؤال.
- تمييز معلومات المنصة عن الشرح التعليمي العام.

حدود مهمة:
- ذاكرة المحادثة محفوظة في LocalStorage على الجهاز/المتصفح فقط، وليست مزامنة بين الأجهزة.
- المساعد يقرأ بيانات المنشورات وروابط الملفات؛ لا يستخرج تلقائيًا نص ملفات PDF/Word الموجودة خلف الروابط.
- لا يقرأ النتائج أو الشكاوى أو بيانات الطلاب الخاصة، لحماية الخصوصية.
- التصحيح التعليمي ليس اعتمادًا رسميًا، ولا يستبدل تصحيح المدرسة.
- الصورة تُرسل إلى مزود الذكاء الاصطناعي عبر Worker؛ لا ترفع صورًا تحتوي بيانات شخصية.
